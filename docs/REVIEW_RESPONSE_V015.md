# Technical review disposition, 20 October 2026

The supplied PDF and LaTeX review were read as reference material. Their proposals were evaluated against the user's project and existing eight-second local / ten-second nearby-search limits. Original review files are preserved locally and excluded from the public source. This document records implementation choices, evidence and work that needs real equipment; it does not claim every proposed extension was necessary.

| Review topic | Disposition and evidence |
|---|---|
| Question, hypothesis, existing strengths, scientific threats and priorities | Primary deliverable is the 1D sensor-response/vertical-speed experiment. Legacy behavior retained; no novelty, field readiness or adaptive superiority assumed. `RESEARCH_V015.md` defines the hypothesis and mixed results. |
| P0 impossible retrace | Algebra checked across allowed tau values in `thermal_estimator_test.cpp`. `ProbeModel.h` computes required/available distance and full feasibility before motion. Explorer explicitly labels bounded partial inspection; preserves user limits. |
| Static plane fits versus dynamic observations | New primary 1D forward model in `ThermalEstimator.h`. Existing 2D plane map is a secondary heuristic and is not claimed to reconstruct instantaneous water from delayed readings. Dynamic 2D regression deferred. |
| Legacy sampler uses lag only as cap | Renamed `AdaptiveLegacy`; kept as mode 0. New estimator and policy modes 4/5 are independently selectable, with fixed-medium baseline. |
| Clean exploration and assumed position | `ObservationPipeline` separates probe thermal state from noisy digital observations. Controller exploration accepts estimated x/z/velocity with configured errors. Native 1D tests exercise broader disturbances. Browser free swim remains a separate exact-coordinate model. No real localization is claimed. |
| Visited versus informative | Passage bitmap retained for avoiding loops. UI/docs explicitly distinguish it from information/confidence. Unused recheck metric renamed reserved; no invented count. Revisit uncertainty and information scoring deferred. |
| Dynamics, mission limits, reporting | Common dynamics, model-based return reserve and hard cap. Surface completion, reached bottom, full profile, early budget return and faults logged separately. Energy remains a toy proxy. No physical thrust model claimed. |
| Software hygiene | Pure estimator/policy helpers, fixed buffers, bounded parsing, new scenario/evaluation modules, immutable run directories, regression tests and CI builds. No framework rewrite. |
| Coordinates/units, first-order response, noise/calibration/position, synthetic boundary and spatial lag | Positive-down metres/seconds/°C conventions documented. Exact exponential sensor recurrence and initial-state regressors. Separate actual/assumed tau, uncertainty/offset/drift/error inputs and evaluator-only truth. |
| Inverse filtering | Deliberately excluded from production because differencing noise is unnecessary for the selected forward-model approach. Raw observations retained for later offline ablation. |
| Forward model and first-year 1D simplification | Implemented checked local 2×2 solve with filtered regressors, initial reading term, actual timestamps, support-depth association and current-depth diagnostic. Ramp, reversal, jitter, noisy-flat and stale tests. |
| Recursive fit/RLS | Deferred: twelve-record batch solve fits Nano with bounded memory and is simpler to audit. Implement only if measured runtime or window behavior justifies it. |
| Tau uncertainty | Nominal and upper tau separate; actual tau varies independently. Flow-dependent true tau and mismatch sweep supported. Model-bank tau identification is a stretch goal; no claim residual gates identify tau correctly. |
| Confidence | Span, pivot/conditioning, residual, uncertainty proxy, warmup and finite checks. Ungated ablation still requires geometric/safety validity. Proxies are not calibrated intervals, and position noise biases the fit. |
| Control goal, robust speed, anti-oscillation | Scalar governor with epsilon/tauMax/gradient, min/max, conservative fallback, dwell, persistence and acceleration limit. Logs floor/rate/hysteresis reasons and achieved-speed lag proxy. No guaranteed epsilon bound. |
| Candidate-score search | Deferred optional second policy; robust scalar policy is the reviewed first implementation. No fabricated information-gain optimizer. |
| Mission feasibility above sampler | Common allowance reserve and supervisor dominate speed choice. Tests include truncated profiles and explicit failures. Reserve itself requires plant calibration. |
| Honest state machine and spatial revisit | Full feasibility gate plus partial status in existing bounded exploration; main experiment descends/holds/ascends without horizontal detours. Spatial redesign deferred until 1D validation. |
| Research estimator versus safety, per-tick algorithm and cheap governor | Modules separate fitting and speed choice; Controller retains stale/leak/depth/battery/tilt/current/arm/timeout checks. External bench inputs cannot enable motors. |
| CPU/SRAM/float budgets | Actual AVR compile showed combined-image overflow. Two capability-advertised images fit; native lab includes both. On-board decision timing and stack-paint measurements complement static sizes; future drivers not included. |
| Firmware test list | Desktop ramp/step-like thermocline/reversal/noise/stationary/degenerate/invalid/stale/rollover tests, parser sequence/overflow/interlock tests, real Nano route/parity/fault/timing checks. Physical electrical noise and integrated driver timing remain pending. |
| No truth leak | Controller ABI receives raw measured T, estimated depth/velocity and timestamps only. Truth fields are separate evaluator outputs. Gates/policy never read the scenario's true boundary/gradient. Tests inspect observation payloads. |
| Disturbances and scenario generator | AR noise, bias/drift, quantization, position/velocity errors, packet gaps/jitter, moving layer, probe offset/tau-flow mismatch and plant parameters. Deterministic disjoint split seeds. 2D missing-observation handling is currently fail-closed. |
| Dashboard and lab priorities | Six strategies, raw/forward reconstruction selector, coverage/failure denominators, paired intervals and gradient/residual/speed/reason diagnostics. No CFD/ROS/3D/neural interface added. |
| Fairness, baselines and ablations | Fast, slow, medium, legacy, new and ungated use common maximum allowance/dynamics. Raw/forward scoring separates estimator from adaptation. Equal actual duration/energy is not claimed. |
| Ground truth/scoring | Fixed required grid and search interval, strongest gradient peak, absent full RMSE on missing bins, conditional/shared errors and failure/false-peak counts. A moving-profile reconstruction is time distributed. Detection-delay measurement remains a later analysis extension, not silently inferred from boundary position. |
| Selection/final evaluation and intervals | 20 nominal + 20 varied + 20 one-factor development scenarios; freeze settings/source; 30 independent varied held-out scenarios. Scenario bootstrap conditional on joint detection; no sample pseudoreplication or powered confirmatory claim. Evaluation exposed failures and no consistent win. |
| Suggested sweep | Development one-factor true tau, width, noise, position error, moving boundary and dropout bursts. Held-out varied mixture. Full Cartesian product and model-bank comparison deferred. |
| Phase 0 arithmetic/reproducibility | Retrace test, manifests/hashes, exact saved-data rescoring, frozen-source check and mixed-result report implemented. |
| Phase 1 physical calibration | Step-fit tool, synthetic recovery test and wet protocol prepared. Actual reference instrument, probe, bath and representative flow still required. No invented calibration values. |
| Phase 2 Nano HIL | Both firmware images exercised on the connected motor-disabled board. See local `output/logs/nano_v015_*` evidence and firmware guide. |
| Phase 3 vertical rig | Actionable protocol prepared. No rig, reference profile or measured energy yet; these cannot be completed in software. |
| Phase 4 vehicle integration | Optional future engineering: real drivers, logging, hull, thrusters, localization and verified recovery. Current bench firmware intentionally remains simulated/motor-disabled. |
| Minimum deliverable and stretch goal | Implemented 1D software experiment with honest limitations; physical minimum deliverable remains pending. Recursive/model-bank/2D information-planning stretch goals excluded from current performance claims. |
| Derivations and patch sequence | Initial-condition recurrence and spatial lag applied; noisy inverse differencing avoided. Existing behaviors preserved as baselines; staged implementation followed by tests, hardware checks and documentation. Public update uses source-only allowlist. |
| Repository passages/background reading | Historical docs retained as history with current-guide pointers. The review is a critique, not validation or a substitute for focused literature review and independent probe calibration. |

The review's central scientific objection is borne out by the held-out results: reducing sensor lag in a nominal illustration does not establish that adaptation improves every profile. The updated project can now test and expose that distinction. Further algorithm changes must use a new development cycle and a new held-out set.
